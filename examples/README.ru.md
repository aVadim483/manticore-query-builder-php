# Запускаемые примеры

[English](README.md)

## Пакетный импорт, JSON-фильтры и гибридный поиск

`hybrid-search.php` создаёт локальную RT-таблицу с уникальным именем, загружает пять
документов из генератора тремя пакетами, применяет JSON-фильтры и составной
полнотекстовый поиск, объединяет независимые текстовую и векторную выдачи через RRF
в PHP и получает страницу окна результатов. Скрипт печатает один JSON-отчёт,
предварительно удалив созданную им таблицу.

Нужны тестовый Manticore с SQL-доступом, правами создания/удаления RT-таблиц
и библиотекой KNN; подходят проверяемые версии выпуска 28.6.6, 29.9.0 и `latest`.
Также нужны PHP 7.4 или PHP 8.1+, Composer-зависимости библиотеки и PDO MySQL.
Buddy и провайдер эмбеддингов не требуются: векторы заданы прямо в примере
и демонстрируют механику поиска, а не смысловую близость реальных текстов.

Из рабочего репозитория или распакованного исходного архива:

```sh
composer install
php examples/hybrid-search.php
```

Из приложения, в котором эта версия пакета установлена через Composer:

```sh
php vendor/avadim/manticore-query-builder-php/examples/hybrid-search.php
```

По умолчанию используется `127.0.0.1:9306`. Для отдельного тестового экземпляра:

```powershell
$env:MANTICORE_HOST = '127.0.0.1'
$env:MANTICORE_PORT = '19306'
php examples/hybrid-search.php
```

```sh
MANTICORE_HOST=127.0.0.1 MANTICORE_PORT=19306 php examples/hybrid-search.php
```

Необязательные `MANTICORE_USERNAME` / `MANTICORE_PASSWORD` задают SQL-аутентификацию.
Успешный отчёт не содержит учётных данных. После проверки восстановите переменные
окружения, если возвращаетесь к другому серверу.

В JSON выводятся:

- `batch`: пять подтверждённых входных документов и три выполненных SQL-пакета;
- `fulltext`: документы 1, 2 и 3 обычного составного MATCH с общими фильтрами;
- `hybrid`: результаты 3, 1 и 2 с итоговыми оценками, данными ветвей и метаданными;
- `page`: документ 2 на второй странице при размере страницы 2.

Документ 1 приходит из текстовой ветви, документ 2 — из векторного окна, документ 3 —
из обеих ветвей. Фильтры остатка и JSON исключают документы 4 и 5 из обоих поисков.
Скрипт проверяет ожидаемый результат и завершается с ненулевым кодом при ошибке
или неудачном удалении таблицы. Удаляется только таблица со случайным именем после
подтверждённого CREATE; существующие таблицы приложения скрипт не удаляет.

`window_total` равен 3, а `total_found` — null: страницы материализованного окна
не дают общего числа совпадений и не выполняют новый SQL. Экспорт гибридного
результата содержит документ, итоговую оценку, ранги текста/вектора и метаданные ветвей.
API и ограничения описаны в [руководстве по KNN и гибридному поиску](https://github.com/aVadim483/manticore-query-builder-php/blob/main/docs/ru/knn-hybrid.md)
в репозитории. Каталог `docs/` не входит в релизный dist-архив; запускаемый пример
и этот README входят.

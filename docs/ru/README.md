## Выбор способа получения результата

| Задача | Метод |
|---|---|
| Строки с автоматическим получением метаданных | `Query::get()` |
| Строки и метаданные в одном объекте результата | `Query::search()` |
| Строки без SHOW META (2.6) | `Query::getRows()` |
| Явный запрос текущих метаданных соединения (2.6) | `Query::getMeta(): Meta` |
| Загруженные метаданные как массив | `ResultSet::meta(): array` |
| Загруженные метаданные как неизменяемый объект (2.6) | `ResultSet::metaObject(): Meta` |
| Проверка наличия загруженных метаданных (2.6) | `ResultSet::hasMeta(): bool` |
| Пакетная запись из iterable и диагностика пакетов (2.7) | `Query::insertBatch()` / `replaceBatch(): BatchResult` |
| Объединённые кандидаты гибридного поиска и диагностика (2.7) | `Query::hybridSearch(): HybridResult` |
| Документы гибридного поиска как массив или первая строка (2.7) | `Query::hybridGet()` / `hybridFirst()` |
| Сериализуемый результат гибридного поиска (2.7) | `HybridResult::toArray()` / `json_encode($result)` |

Возможности с отметкой 2.6 доступны начиная с [2.6.0](../../CHANGELOG.md).
Возможности с отметкой 2.7 доступны начиная с [2.7.0](../../CHANGELOG.md).
Прежнее поведение по умолчанию сохраняется.

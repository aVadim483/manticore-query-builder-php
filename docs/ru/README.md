## Выбор способа получения результата

| Задача | Метод |
|---|---|
| Строки с автоматическим получением метаданных | `Query::get()` |
| Строки и метаданные в одном объекте результата | `Query::search()` |
| Строки без SHOW META (2.6) | `Query::getRows()` |
| Явный запрос текущих метаданных соединения (2.6) | `Query::getMeta(): Meta` |
| Загруженные метаданные как массив | `ResultSet::meta(): array` |
| Загруженные метаданные как неизменяемый объект (2.6) | `ResultSet::metaObject(): Meta` |
| Проверка наличия загруженных метаданных (2.6) | `ResultSet::hasMeta(): bool` |

Возможности с отметкой 2.6 доступны в `main`, в разделе [Unreleased](../../CHANGELOG.md).
В опубликованном релизе 2.5.0 их пока нет. Прежнее поведение по умолчанию сохраняется.
Подробности — в разделах о поиске, ResultSet и записи документов.
